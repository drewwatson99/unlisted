# Letter templates

The web app and CLI generate these automatically with your details and the
statute for your state. These copies are here for reference, for editing, and
for sending by post to brokers that only accept mail.

- `initial.md` — first deletion request
- `followup.md` — day-30/45 second request
- `final.md` — day-90/120 final notice before a regulatory complaint

## Cadence

| Day | Action |
|---|---|
| 0 | Initial request |
| 30 | Follow-up if no confirmation |
| 45 | Follow-up — most state statutes require a substantive response by now |
| 90 | Final notice |
| 120 | Stop. Automated escalation ends; handle this broker by hand. |

Stopping at 120 days is deliberate. Indefinite automated resending to the same
inbox reads as harassment, gets filtered as spam, and undermines the legitimacy
of the request.

## Which statute applies

Deletion rights are state law, and they vary. The tools pick the right citation
from your state. If your state has no consumer privacy statute in force, the
letter is written as a courtesy request instead — many brokers honor those, but
be aware there's no deadline behind it.

If you are a **California resident**, use https://privacy.ca.gov/drop/ instead
of sending letters one at a time. One verified request reaches every registered
broker, and they are legally required to act on it.
