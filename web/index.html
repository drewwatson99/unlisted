Unlisted

data broker opt-out workbench

A free, open tool for getting yourself out of data broker databases — the same work removal services charge $20–130/year for. It ranks brokers by how much they actually expose you, walks you through each opt-out, drafts your legal deletion letters, and schedules the follow-ups.

Nothing you type here leaves your device. There is no server, no account, and no database — the page has no way to send your details anywhere.
Read this before you use this tool

If you live in California, use the state's own platform instead

California built something better than this tool, and it is free. Under the Delete Act, the California Privacy Protection Agency runs DROP — the Delete Request and Opt-Out Platform. You submit one verified request and every data broker registered in California must delete your personal information and stop selling it.

It is not a courtesy request. Since August 1, 2026, brokers are legally required to check DROP at least every 45 days, process the deletions, and report back. Non-compliance carries penalties of $200 per request, per day. Several hundred thousand Californians have already signed up.

It also covers cases this tool deliberately does not: a parent can submit for a child, and a family member can submit for an elderly relative.

So: if you are a California resident, go do that first. It is strictly better than working through this list by hand, and it costs nothing. Come back afterward only for the gaps below.

  • Brokers that never registered in California. DROP only binds registrants — plenty of people-search sites simply do not register. Those are in the list below.
  • Verification. DROP does not show you whether a given listing actually came down. This tool tracks that.
  • Everyone else. DROP is California residents only. Connecticut has committed to a similar portal but not until 2028. Texas and Oregon maintain broker registries with no unified deletion portal — you must contact each broker yourself, which is exactly what this tool is for.

3 · Follow-ups & backup

Brokers routinely ignore a first request, and records repopulate months later. Download a calendar file with follow-up reminders for everything you have submitted — it imports into Apple, Google, or Proton Calendar and fires even with this page closed. Reminders land at 30, 45, 90 and 120 days; after 120 days the escalation stops and you get one final nudge to handle that broker by hand.

Export writes a plain JSON file to your downloads folder so you can back up or move to another browser. It contains the details you entered above, so store it like any other personal document.
